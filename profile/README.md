# Starbounded Studio

**Small studio. Big workbench.**

We're an independent software studio based in Canada. We build tools for making interactive worlds, and share the work as it takes shape.

## On the workbench: LuxEngine

[**LuxEngine**](https://github.com/starbounded-dev/LuxEngine) is our early-stage C++ game engine for Windows. It's where we're working through engine design in practice: writing the systems, trying them in a scene, and understanding the decisions behind them.

The current tools include:

- **Scene editing** — a scene hierarchy, content browser, and viewport.
- **Material editing** — surface, emission, and texture controls with a preview.
- **Rendering experiments** — scenes for exploring lighting, reflections, and materials.

There's still a lot to build. The source is open so you can look around, try a change, or follow the progress.

[Explore the source](https://github.com/starbounded-dev/LuxEngine) · [Meet LuxEngine](https://starbounded.com/lux)
